# Audit, 2026-11-24: security, performance, storage

Evidence: [`audit-evidence/2026-11-24/`](./audit-evidence/2026-11-24/) (`baseline/`, `after/`). Both sides ran on one host: the image limited to 4 cores and 8 GB, on a throwaway Postgres seeded with 50 users and 1,020 projects.

## Measured

| | Before | After |
|---|---|---|
| Chat page, first-load JS (gzip) | 794 kB | 500 kB |
| App shell pages, first-load JS | 372-381 kB | 342-353 kB |
| Chat page, static bytes when loaded | 3.17 MB | 0.63 MB |

| Advisories (critical / high / moderate / low) | 5 / 37 / 63 / 21 | 0 / 1 / 1 / 0 |
| Tests | 3596 pass, 1 fail, 2 skipped | 3623 pass, 2 skipped |
| Server load run, 50 users, 5 min | 0 errors | 0 errors, figures within noise |
| This machine's free disk | 15 GB (end of work) | 59 GB |

The server was not the bottleneck (event loop 14% busy, slowest common query 0.3 ms), so it was not rewritten. Slightly worse: prefetch p50 went 55 to 61 ms and its p99 101 to 120 ms, in single runs with no repeat; it may be noise.

## Security

| # | Was | Now |
|---|---|---|
| S1 | public `/file?path=.env/.`, or a symlink, read `.env` | every segment and the real path are checked |
| S2 | IPv6-mapped, NAT64 and 6to4 addresses passed the SSRF filter; `web_fetch` could be rebound | addresses are parsed, and checked when the connection is made |
| S3 | a ticket worked after sign-out; expiry and a password change left sockets open | a session's end drops its tickets and closes gateway, browser, collab and preview sockets. Losing a project also ends terminals there |
| S4 | a preview cookie lasted 12 h whatever happened | holds only with the live session and membership. Old cookies are replaced through the normal redirect |
| S5 | any client could forge its address past the sign-in limit | `TRUSTED_PROXIES`, plus a per-account limit that never holds back addresses that signed in before |
| S6 | 126 advisories | 2, both explained below |
| S7 | sign-in took a password of any length | capped at 1,024 characters |

Upgrading drizzle brought one trap: its new error text lists every query parameter (password hashes, tokens) and hides the driver's error code. `packages/db` unwraps it, with a test.

**Remaining advisories.** `zod` (high, memory use on oversized arrays; fixed only in v4): bodies are limited to 1 MiB and socket frames to 1 MiB, and no signed-out route validates an array. Moving to zod 4 is its own task. `minimatch` (moderate): only inside `shadcn`, a build-time tool.

## Storage

- Migration 0050: two indexes for the agent tables' cascades; two redundant project indexes dropped. No rows touched.
- `AUDIT_RETENTION_DAYS`, off by default.
- A failed `ucch-backup` no longer leaves a partial folder that counts as one of seven kept.
- Image: 112 MB of third-party source maps and a duplicated server build removed.
- Local cleanup: stale build output, orphaned packages, 53 GB of Docker build cache. No images or volumes other than those this audit made.

## Not done, and why

- **CSP**: unchanged. A script policy needs nonces through Next and checks with draw.io, tldraw and widgets; nothing smaller added protection.
- **`lz4` columns**: no measurement supported it.
- **Dev database sizes**: `ucch-pg-dev` was stopped, and was left so.
- **Preview revocation** is proven by tests with real HTTP and WebSocket servers, not clicked through in the image.
- **Node 22** (clean environment): 3620 pass, 4 skipped, 1 fails: a PDF fixture so short that the image's tesseract re-reads it. That code is unchanged.

## Remaining risks

- **F5**: every account shares one OS user, so accounts can read each other's workspaces and CLI logins. Only give accounts to trusted people.
- A client on a private network that reaches the port directly, with no proxy, counts as a trusted proxy and can still forge its address. The per-account limit holds. Set `TRUSTED_PROXIES=loopback` or `none` there.
- Behind Cloudflare its ranges must be added to `TRUSTED_PROXIES`, or visitors share addresses, as before.
- The container takes 60 s to stop, before and after this work. Not investigated.

Four Playwright specs (`api-keys`, `coedit-file`, `compact`, `compaction`) had selectors or text from older versions of the interface; they were repaired, and the whole suite passes.
