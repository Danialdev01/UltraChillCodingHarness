Fonts placed here are handed to Typst with `--font-path`, ahead of the system's.

The template asks for Inter, then IBM Plex Sans, Noto Sans and DejaVu Sans, and JetBrains Mono for code. The server image installs these from Debian packages. Drop `.ttf`/`.otf` files here to pin exact versions, or to use a house font. If you do, change `tokens` in `templates/base.typ` to match.
